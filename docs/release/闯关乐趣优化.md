# 闯关乐趣优化 · 2026-10-27

适用项目：拾色 / graft。保留十二关材料改造与平台跳跃，延续已有拼豆图册。

## 从试出办法中获得乐趣

| 要素 | 本轮落地 | 希望观察到的体验 |
| --- | --- | --- |
| 目标感 | 根据身体高度、所在位置、开关与门的状态，只展示眼前的一步；完整玩法收进暂停页 | 玩家知道现在能尝试什么，又不会提前被整关说明淹没 |
| 操作感 | 关闭豆板后说明跳高或形状变化；提示停留时间随字数增加；修复材料与角色中心重合时的拾取异常 | 一次削豆或贴豆能带来可理解的变化，接着就想试跳、试钻 |
| 挑战感 | 第 1、5、7 关增设安全复活点；失败后给具体操作建议；光种仍是可选挑战 | 能先学会过关，再自己决定是否挑战高处收集，失败不用重复所有步骤 |
| 成就感 | 通关页保留等待玩家操作；用十二颗豆子记录足迹，显示最佳收集与更少散架的进步；选关显示已通关与无散架记录 | 成功有停下来品味的空间，能看出自己比之前熟练 |
| 探索感 | 通关页预告下一关的材料机制；直接进入已解锁的拼豆图册，完成后回到通关页 | 对下一种玩法有期待，也能随时停下来把探索成果做成挂件 |

主循环是：观察障碍 → 试着改造 → 看见身体变化 → 尝试过关 → 留下作品或继续探索。
没有额外体力、签到惩罚、限时领取或强制收集门槛。

## 界面选择

沿用洞穴与手工豆板：壳紫 #211b2d、浅米 #f3e6cc、豆板金 #dfc29b、叶绿 #9dd775、灰紫 #b9accb。宋体只用于通关页标题，系统中文承担说明，沿用等宽数字记录关数和光种。

关内提示是小条；通关成果是独立的可滚动面板，不挤在手机游戏画面里。标志性结构是一串十二颗豆子，每颗对应一关。最初考虑把五类目标都常驻画面，复核后删掉：关内只保留当前目标与一条可选探索信息，成长记录放在通关页和选关页。

## 第二轮：提高关卡难度、适配手机

保留前期教学，重点把第 8、9、12 关从单一材料直走，提升为跨楼层取材、控制重量、保留材料和重新改形的组合挑战。

- 森林关：草种芽与上层水徽记共同开门。水放在第一层右端，需要借藤蔓取到，再乘蘑菇返回上层；不能只带草一路向右。
- 配重关：中层踏板要求重量在 12.5–15.5，持续站稳 0.7 秒。过轻、过重和中途离台都不能完成校准；进度条实时显示，暂停时冻结，完成后永久开门。
- 最后一关：底层校准后依次用水、火开路；中层火灯与水柱联合开门，中间新增两格高窄道。必须在材料与形状之间安排顺序，最后再带草登顶。
- 手机竖屏：画面、目标条、底部手柄分开；兼容小屏高度，不要求先横屏。
- 手机横屏：3:2 画面放中间，左侧方向、右侧跳跃与豆板；目标条在画面上方。手指不覆盖平台落点。
- 豆板和暂停页改成覆盖手机视口的浮层，重要按钮至少 44px；屏幕旋转时释放移动和跳跃状态。

新增 challenge.js 验证配重上下限、计时重置、暂停、联动顺序和窄道碰撞。mobile.js 覆盖 320×568、390×844、430×932 及对应横屏的画布尺寸、双指输入、旋转与编辑隔离。adventure.js 支持通过触屏事件处理器移动与轻点跳跃，路线使用真实物理、拾取与改造，不传送角色或直接改机关状态。上述是逻辑测试，手机浏览器排版和真机手感仍需实际试玩验收。
