# 四区拼装冒险 · 本地试玩

2026-11-01。用户要求继续在本地优化；未提交、未推送、未部署。

## 本轮解决的问题

旧战役只有一张地图、两至三段怪物和隐藏的首领激活条件。休闲拼豆与战斗属性没有联系，元素快捷切换也没有让玩家获得拼装取舍。

新主循环：打捞场 → 断桥通道 → 精英前哨 → 首领大厅。五章共二十张区域配置，前三个区域走通只进入下一片场景，不结算通关、不解锁下一章。第四区有明确名字和模型的必经首领，击破后才开启章末出口。选章缩略图也绘制对应首领。

## 拼豆直接变成装备

参考《羊了个羊》的表层取牌和有限暂存取舍（[TapTap 玩法讨论](https://www.taptap.cn/app/238441/topic?type=strategy)）。本作以四格工作台、两豆配方、三处角色挂点实现战斗拼装；不是三同色消除，也不沿用其图案、关卡和失败设计。

- 从每堆最上面取豆，下面的颜色可预览；暂存豆可免费归还，满四格不直接判失败。
- 火＋火：双管炮，增加伤害与射速。
- 水＋水：穿流枪，增加射程、穿过小怪继续命中。
- 岩＋岩：岩盾，按等级每区抵挡一至三次伤害，进入下一区补满。
- 草＋岩：藤索，一次腾空可额外跳一次，用原跳跃键。
- 火＋水：蒸汽炮，每四发一枚爆炸弹，伤害邻近对手，同样作用于首领。
- 最终章光＋光：照明翼，持续驱散暗影并延长射程。
- 三处挂点可选择替换；同款自动升到三级。每区有十六颗基础补给，战场拾取的战利豆会追加进料堆。每份掉落有稳定编号，复活、刷新后重打同一只敌人不会重复增加拼装库存。组件实际绘在工台战士与场上角色身上。

首次区域至少拼一件组件；精英前哨前需再完成一次拼装或升级。元素仍然一键切换，组件被动生效，不新增战斗技能按键。打开拼装台会暂停战斗，返回时清掉持续移动/攻击输入。

## 路线与重试

第二区有两处不同元素开关、联动门、浮台和上下路线；第三区有精英、远程预警、喷口和充能支路。高台增设可用的踏脚点，首领仍有跨层预警、跃击与分阶段护盾。拉远战斗镜头，增加上下路线和首领的可见范围。

区域间继承组件。死亡从当前区域或本区青旗继续，不回整章开头；青旗保存当时的守卫和机关状态。菜单“重来当前区域”恢复该区入口状态。按区域写入本地存档，“继续冒险”从当前区域入口恢复组件与剩余补给，敌人、机关重新开始。损坏或重复材料的装备存档被拒绝。
