# 逐光之旅交互修订 · 2026-10-30

根据“抽象、不易切换、技能释放失败、只有首领战”的反馈，本次改为先探索练习、关底挑战的旅途。

- 入口改名“逐光之旅”。五章改为余烬海岸、回声湿地、断层峡谷、蔓生庭院、无光之城；首领名称同步调整。
- 初始只展示水、火两项，进入直接带水技能，不强迫打开拼豆板。下方元素栏点选即可切换。每章清理两队小怪后向右抵达关底，首领才启动；退出范围不能冻结已启动的首领。出口须击败首领才开启。
- 通关下一章逐步增加草、岩，最后解锁光和雾。采用通关解锁，没有新增等级或经验系统。
- 普通小怪具有元素弱点：水对火、火对草、草对水、岩破甲、光对暗。攻击自动瞄准普通小怪；没有元素配方的旧探索关也能普通攻击。
- 已解锁的旅途技能不再因受伤、材料不足或配方断开而突然不可用。切换时尽量用实际材料重排外形，材料/空间不足则保留当前外形，技能仍可切换。拼豆板成为可选的外形编辑，不是施法入口。
- 攻击按钮固定叫“攻击”，技能和冷却放进独立状态条。提示直接说水/火等元素，避免技能名与元素按钮对不上。
- 手机竖屏把攻击、跳跃、豆板安排在独立按键区；切换栏不与攻击键重叠。保留多指移动与释放隔离，补充原生 click 作为键盘/触屏激活入口。

验证：默认即能施法、点击换元素、掉豆后保留技能、材料不足仍能切换、普通攻击、两队小怪门槛、关底才启动首领、已启动不后退冻结、通关解锁均有测试。完整回归通过；Chrome 320×568、390×844、844×390 和桌面验证了真实点击/轻触、攻击与切换栏不重叠、普通怪物命中和暂停。首领难度与实际微信真机体验仍需进一步试玩。

本说明更新上一版《元素远征》中“所有技能都要依赖身体上两颗相连豆子”的强制规则；旧探索自定义拼装仍可识别配方，旅途改用已解锁的技能选择。
