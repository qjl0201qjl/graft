# 豆岛打捞试玩 · 2026-10-28

参照用户指定作品时，提取的是交互与成长结构。益世界和官方入驻页面将《疯狂水世界》定位为海上末日模拟生存、拾荒建造；《羊了个羊》的官方介绍强调规划顺序与善用道具。本轮据此选择“单指选择 + 有限篮子 + 拼出作品 + 豆岛成长”。不沿用原作品角色、美术、名称、文案或关卡，不以其宣传的通关率作为我们的难度目标。

参考：[益世界](https://www.eworld.cn/)、[疯狂水世界官方介绍](https://www.taptap.cn/app/790816/all-info)、[羊了个羊官方介绍](https://www.taptap.cn/app/238441)。设计效果属于待试玩验证的判断，不是已证实的留存结论。

## 设计计划与复核

原有平台闯关需要双指移动、跳跃和中途改身体，对于只想轻松拼豆的玩家学习成本较高。新增首页推荐入口“打捞拼豆”：点三颗同色豆子 → 一组自动拼进图纸 → 完成作品装点豆岛并收入原图册，可戴回遗迹闯关。

水面浅青 #dceff0、帆布白 #f7f6e9、海墨 #244954、绳金 #c19a67、粉豆 #ff9eaf、叶绿 #9dd775；其余豆色继续沿用已有材料颜色。标题用宋体，规则和操作用系统中文，数量用等宽数字。手机布局从上到下为岛屿、当前作品、可点豆子、六格篮子和两项辅助；桌面拆成作品与打捞双栏。

标志元素是“六格绳篮把散豆送进实物拼豆作品”，而不是通用消除卡片。第一轮只用两种颜色与六颗明豆，随后逐步增加种类与明豆数量；所有豆子可直接点，没有精细拖拽或手速要求。篮子满时可撤回，提示只标出可组成一组的颜色。不给玩家增加付费复活、强制广告或断崖式第二关。

复核：纯粹再加一个三消会把拼豆变成装饰。这里每次成组直接填作品，完成后给原图册一件可佩戴成品，六个作品逐渐摆满豆岛；平台闯关保留为另一入口，两种操作方式由玩家选择。

## 可解性与进度

每种颜色按作品需求向上取整为三颗一组，最多同时出现四组明豆；消掉一组后补充下一组。牌面与篮子中的剩余数量始终守恒，按颜色先成组存在可完成路线，难度来自取豆顺序而非无解随机局。

按操作保存当前篮子、明豆、待补组、作品进度和有限撤回历史，关闭或刷新后继续。首次完成记录豆岛作品，重复游玩不重复发成品。旧的光种与背包不消耗，原本手动拼出的成品也保留。

## 本轮验收

- 六张图纸分别检查 40 次不同变序，共 240 个可解局；另测篮满失败、撤回后恢复、刷新保留撤回历史、重复完成不重复发奖、越级操作与坏存档重建。
- 检查与原游戏的隔离：豆岛内暂停闯关更新，关闭后没有残留移动输入，成品入册不改变关内库存和身体，也不发放光种。
- 完整逻辑回归通过，保留已有十二关、30/60/120 FPS 与触屏通关测试、机关组合、复活、手机旋转和口令网关检查。
- Chrome 桌面、390×844、320×568 和 844×390 手机模拟中，实际点击/轻触完成一局、提示、撤回、重开续玩、成品入册、下一件、暂停进入豆岛与 Escape 返回均通过。补测小屏篮满页面恢复与原有豆板、成果页往返；生产压缩包无调试钩子且可正常打开新模式。

以上是浏览器与自动检查，未做真实 iPhone / Android 微信客户端测试，也没有留存数据。
