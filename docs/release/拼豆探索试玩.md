# 拼豆探索试玩 · 2026-10-27

这是供实际试玩验证的第一种方向，尚不是已验证的留存方案，也不是微信原生包。

## 方向比较与本轮选择

1. 拼豆作品成为闯关挂件：过关找光种 → 解锁图纸 → 选色穿豆 → 熨烫收藏 → 戴着作品继续冒险。保留现有玩法、作品归属感明确，本轮先落地。
2. 每关先拼一个工具再解谜：桥、雨伞、钥匙由图纸组装，重点转为观察与组合，减少对跳跃精度的依赖。适合下一轮小样；还没有实现。
3. 拼豆小岛经营：关卡捡来的图纸摆进自己的展柜，持续装饰场景。内容需求高，先验证前两个方向是否好玩；还没有实现。

当前不是把无限工坊豆子搬进关卡。图册与关内背包分开，挂件只有外观用途；功能豆的重量、火水草机关仍按关卡材料结算。

## 视觉计划

保留遗迹夜色，豆板成为唯一醒目的手工工作台：夜紫 #211e31、豆板木色 #e9d6bd、粉豆 #ff9eaf、叶绿 #9dd775、水蓝 #78d9e7、熨烫金 #ffc371。宋体仅用于工坊题头，系统中文用于操作，等宽数字用于豆数。桌面是图纸抽屉 / 豆板 / 颜色盒三栏；手机先横排翻图纸，再大豆板和工具。标志性元素是有孔、带厚度的圆柱豆子，浅色图纸做底、实色豆子叠在上面。

对照需求复核：单纯改成圆色块仍不算结合拼豆，必须有图纸、逐颗填色、完成作品以及回到冒险中展示的闭环。不给玩家增加战斗按键，不用每日签到或惩罚缺席代替内容吸引力。

## 本轮交互

- 首张图纸免费；后续需要累计 2/5/9/14/21 颗光种，解锁不扣光种。
- 光种按关卡和位置去重，拿到即保存，重试不清掉图册进度；旧版本最佳收集数保留为累计下限。
- 图纸有浅色底稿；选色后点按或滑动穿豆，选错会提示所需颜色；可撤回未熨烫的豆子。
- 填满后手动熨烫收藏，自动佩戴；重新进入或刷新可继续未完成作品，也能取下挂件。
- 手机左右键、轻点完整跳跃；豆板暂停操作，快捷瘦身 / 收石 / 贴豆都遵守实际库存、连通性与碰撞规则。
- 键盘仍允许长短跳；手机不再直接点正在移动的小身体削格。

## 试玩要观察

第一次进入能否独立完成一个挂件；是否理解去关卡找光种能得到新图纸；是否愿意回头找漏掉的光种；豆板操作次数与误点情况；跳跃失败是没按到、太重、撞顶还是平台节奏。没有埋点、没有宣称已验证留存率。

## 验证记录

完整回归通过，既有十二关加载、通关与战斗验证，后半五关在 30/60/120 FPS 下正常通关。新增检查覆盖图纸解锁、选色、未完成图纸不可熨烫、成品不可重复领取、刷新恢复、光种去重、工坊不发放关内材料、单层瘦身、收石与贴豆库存守恒、短按跳高度、双指释放、缓存、边缘宽限与平台角碰撞。

Chrome 桌面及手机模拟中实际点按和拖动穿豆、熨烫、佩戴、刷新、暂停入口、Escape 返回、横竖屏豆板、双指移动同时轻点跳和生产构建加载均通过。这是浏览器验证，尚不能代替 Android / iPhone 的微信真机测试。
