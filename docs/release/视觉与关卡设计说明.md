# 拾色 · 遗迹探险视觉与关卡

## 视觉方向

主角是可拆装的洞穴探险精灵，辨识点是黄铜护目镜、短围巾和灯芯核心。保留像素身体的真实轮廓：变成一条、两格或一大块，脸和饰物仍附着在实际存在的格子上，不以美术遮住已削空的身体。

色彩沿用洞穴六种基色：墨紫 `#161522`、旧铜 `#bc9c76`、暖纸 `#f3e6cc`、叶绿 `#c4ef9b`、水蓝 `#83cbd9`、余烬 `#f3b877`。原有肉色承担主角柔软的身体感。标题使用宋体/衬线中文，操作用清晰的系统中文，数值和小型环境标记用等宽字。

草块表现枝叶纹，水块表现流线与气泡高光，火块表现发光内核，石块表现裂缝与矿光，肉块保留接缝与柔和高光。机关有黄铜连接件与不同材质的标识，不只依赖色彩。背景增加五色遗迹圆盘、残柱和拱形遗址，亮度略提高，让可互动内容从背景中分离。

## 关卡复杂度

前七关继续承担基本教学，不同时灌输所有技能。后半五关增加以下组合：

- 第八关：草唤醒多段蘑菇，种芽搭出可选藤桥，光种奖励旁路探索。
- 第九关：底层重装压板开门 → 收石轻装搭升降台 → 中层再次配重开第二门 → 再轻装登顶。每道门锁定后永久开，避免要求玩家长按或新增按钮。
- 第十关：水关闭底层喷口 → 经小台阶攀上高处，让身上的水点亮共鸣柱 → 回下层穿越剩余喷火节奏 → 消耗水冷却炽热门。
- 第十一关：削矮钻洞、火烧荆棘 → 中层同时激活草种芽和火共鸣柱 → 双徽记联动开门；藤蔓和浮台提供不同的登顶路径。
- 第十二关：保留石、水、火、草连续使用，最后以草蘑菇跳上高台。

共鸣柱不消耗材料；水冷却与灭火消耗一格水。对应材料需在身体上，背包库存不算。机关之间的细线与门旁灯点说明联动状态。复活保留快照里的门、徽记、身体和库存；手动重来清空这一关。
