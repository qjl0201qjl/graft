# 本地重设计 · 待试玩

用户要求本轮不推送 GitHub；仅在本地修改与预览，不更新线上服务器。

## 设计计划

主题是可拆装的拼豆战斗人形，不再以粉色方块和护目镜作为主视觉。钢蓝 #162434、浅瓷 #dbe7ed、信号橙 #ef9b65、冰蓝 #79cae5、结构灰 #40576d、雾紫 #a99ad6。展示标题使用紧凑粗体无衬线，中文操作用系统字体，关号和战绩用等宽数字。唯一的视觉重点是带头盔、胸甲、护肩和武器的拼豆人形；不堆叠发光背景和装饰小标。

首页减少并列入口。战役目录为角色预览 / 章节卡片 / 当前关卡详情与出发按钮。手机先角色与三种造型，再可滚动的大章节列表；点击卡片只选中，确认开始才进游戏。未解锁关卡显示条件。暂停菜单提供同一目录入口，旧训练关使用有全名的大按钮。

复核：只有更换配色仍不能解决“丑和不好选”。因此替换首页布局、主角装甲绘制、完整选关交互，并让关卡卡片说明实际地形和敌人特点。名称改成具体区域与功能，避免再加一套抽象术语。

## 玩法目标

五章标准 / 挑战模式。挑战模式增加第三段战斗、精英与远程敌人，不只是堆血。章节地形与危险区有所区分；高处充能点让绕路探索有实际战斗收益。造型仅改变视觉，难度选择和造型不覆盖旧的解锁记录。

## 完成与验证

已实现三种造型预览与存档、五张章节卡片和缩略场景、独立难度选择与确认开始、暂停页战役目录、旧训练关大按钮、主角头盔胸甲与披风/武器表现。实际角色外观依附现存身体核心；受损与变形不会扩大碰撞体。

挑战模式需要第三段战斗，有更大体型的精英、远程落点预警和更高首领上限；高处一次性充能点、击败精英的充能奖励会实质缩短攻击冷却。五章增加不同阶梯、桥面、脆台或短火路。标准模式仍保留原来的两段战斗流程。

完整回归通过。新增 local-redesign.js 验证章节锁定与确认开始、造型保存、挑战三段门槛和高台奖励，原有出生点检查发现并修复了新台阶中的敌人卡墙问题。Chrome 检查 320×568、390×844、844×390 和桌面；开始按钮位于首屏，选择卡片不会误进关，目录可从暂停返回。生产构建也验证了目录可运行、调试入口已移除。没有进行微信真机或长时间平衡测试。

## 2026-11-01 · 多层首领与关内互动

修复旧攻击把高度固定在地面的问题。攻击开始时读取玩家所在平台并锁定落点；预警后换位可躲避，不持续追踪。熔岩首领使用跨层落焰与斜射，水系首领在玩家所在层发出潮线，岩系首领有实际抛物线登台跃击，草系首领交错棘刺，最终首领交叉封锁。后半血量会额外威胁另一层。身体接触伤害跟随实际高度，斜射遵守墙体阻挡。另修正正上/下方目标的垂直瞄准。

每章加入地面、高台两个元素节点，命中两次才解除，错误元素无效。解除后短时充能；高台需要先找射线通路。保留标准两段/挑战三段防线，前四名首领增加三阶段重整，最终首领保留五种元素换相。生命调整为标准54、挑战78。操作仍是移动、跳、点元素、按住攻击，不增加新键。

战前青旗须清完防线和双节点才能激活。失败重试保留节点、防线、材料与收集物，首领恢复完整生命并清空招式。击败首领立即清理残留攻击。

新增 boss-art.js，以穿孔拼豆、关节、装甲/鳍/枝翼/环绕碎片区分五个二维首领形态；跃击、浮动与发招姿态由实际战斗状态驱动。明亮的中心是碰撞与瞄准核心，装饰肢体不扩大伤害范围。

验证：multilayer.js 在30/60/120 FPS检查五首领的高台伤害、预警后换位、岩系实际登台、垂直瞄准，并以实际投射物验证双节点元素与命中数。战前复活用例验证防线和材料不重复重置。完整回归与生产构建通过。Chrome 390×844、844×390检查高台跃击、五种形态绘制、暂停冻结与运行错误。测试中使用受控位置与无敌进行视觉和机制隔离；仍需真人试玩评估难度与关卡节奏，没有微信真机验证。
