# 元素远征 · 2026-10-30

本轮在原有十二关之后增加五个首领关，首页“元素远征”可直接体验。原有教程与豆岛保留，游戏现为十七关。参考[7k7k《冒险王》介绍](https://www.7k7k.com/special/mxw/)中横版动作、技能与配合的方向，新增规则、美术与关卡为本项目实现。

## 拼出的身体就是技能

豆板提供六种形态图纸：岩锤（侧边竖排石豆）、喷火（火豆相连）、水弹（水豆相连）、藤缚（竖排草豆）、光脉冲（光豆冠）、蒸汽爆（相邻火水）。手动拼装也按身体上的实际连接识别；背包库存不算。图纸只重排现有豆子，保留库存守恒与身体碰撞约束，空间不足不能穿墙变形。光是新增材料。

石锤近距离重击，火、水远程自动朝向首领，草藤命中后束缚首领，光驱散暗影视野，火水混合形态释放范围更大的蒸汽弹。技能不消耗身体，靠冷却限制；首领关中火水不自然退回背包，受伤仍会损失身体并可能失去技能，需要补豆或换形态。原有十二关的火水衰减规则保留。

手机沿用左侧移动、右侧跳跃，增加一个可按住连续施放的技能键，豆板暂停切形态；电脑 J 释放。自动瞄准减少精细指向，但近战仍需靠近、弹道会被墙与关闭的门挡住。形态增加的重量仍影响跳高。

## 五个首领

- 熔火巨像：水或蒸汽击破两层护盾，随后五秒反击窗口；地面火柱和后半场追加火柱。
- 潮汐领主：草藤破盾并束缚；低位冲击波需要跳过或借平台躲开。
- 岩甲守卫：岩锤近身破盾；延迟砸地范围更宽，考验靠近反击和撤离。
- 荆棘女王：火破盾；三处错时藤刺要提前观察落点。
- 蚀光心核：光 → 水 → 草 → 石 → 火五次护盾阶段，光能暂时驱暗；每次跨阶段重新破盾，不能用一种元素连续硬磨。

每个场景有多层平台、三颗可选高处光种、必须击败首领才开启的出口。首领攻击均先亮框再生效，低血量阶段增加冲击波。失败重试恢复本关材料，首领战重新开始，不消耗体力或付费道具。

## 验证边界

新增 tests/elements.js 覆盖六种形态识别、库存守恒、正确/错误克制、五首领通过真实技能弹道击杀、光驱暗与豆板冻结。击杀测试使用受控站位与无敌保护，验证战斗逻辑，不代表普通玩家已经通过完整实战难度验收。

原有回归、十七关加载与生产构建通过。Chrome 手机竖横屏和桌面检查了远征入口、形态按钮、技能按钮可达性、施法与暂停；真实手机、微信客户端、首领难度与长时间试玩仍需验证。未宣称所有关卡已全面重做或新增形态已证明留存。
