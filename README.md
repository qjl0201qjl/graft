# 拾色 / GRAFT

> **你不是在玩一个像素游戏 —— 你这具身体就是像素。**

一个单文件的像素平台跳跃原型:你的身体由几十个 8×8 像素格组成,每一格都是从世界里抢来的材料。受伤是被削掉,变强是贴上去,而你的**形状**决定了你能去哪、打得过谁。

[**▶ 在线试玩**](https://qjl0201qjl.github.io/graft/) · [设计文档 PRD](PRD.md) · [MIT License](LICENSE)

![削成一片钻进墙缝](docs/squeeze.png)

## 核心机制

| 机制 | 说明 |
|---|---|
| **身体 = 格子** | 你是一块 3×3 的肉像素。碰撞体只按包围盒算,所以削瘦了才钻得进缝 |
| **受伤 = 削格** | 没有血条。被撞就掉一格,掉光了就散架。回血不是喝药,是从地上抠材料贴回身上 |
| **材质 = 物理** | 贴什么就变成什么:石重、草轻、水软、火烫 |
| **形状 = build** | 要钻一格的缝,先把自己削成一片;要压塌脆地板,先吃成一块石头 |

### 五种材质

| 材质 | 硬度 | 重量 | 特性 |
|---|---|---|---|
| 肉 | 1 | 1.0 | 默认材质,基准 |
| 草 | 1 | 0.5 | 每 3.2s 自生一格(免费回血),跳得最高 |
| 石 | 3 | 2.8 | 硬碰硬稳赢,能压碎脆地板,但重得跳不动 |
| 水 | 0 | 0.3 | 岩浆只烧水不烧你;会蒸发 |
| 火 | 3 | 0.8 | 撞击高伤,但会烧掉自己 |

硬度关系:**火 = 石 > 肉 = 草 > 水**。战斗不是血条对拼,而是"上场前先改装"的准备题。

## 操作

| 输入 | 行为 |
|---|---|
| `A` `D` / `←` `→` | 移动 |
| `空格` | 跳跃(按住跳更高) |
| **鼠标左键** | 指向身体相邻空位,**贴一格** |
| **鼠标右键** | 指向自己,**削掉一格**(材料回背包) |
| `1`–`5` / 滚轮 | 切换材质 |
| `R` | 重开本关 |

## 四关

1. **壹 · 缝隙** —— 削扁自己,钻过只有一格高的墙缝
2. **贰 · 撑不住** —— 贴石头变重,压塌脆地板掉进下层
3. **叁 · 过火** —— 带水横穿岩浆,水会烧完,别磨蹭
4. **肆 · 硬碰硬** —— 用材质克制打掉三只敌人,解锁出口

## 运行

零依赖、零构建,双击 `index.html` 就行。也可以起个静态服务器:

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

调试参数:`index.html?lv=3` 直接跳到第 4 关;游戏内按 `N` 跳关。

## 技术

- 单文件,纯 Canvas 2D,所有图形用 `fillRect` 画,没有一张贴图
- 内部渲染 640×360(80×45 格 × 8px),2× 跟随镜头
- 身体是一个 8×8 的材质矩阵,包围盒驱动碰撞 —— 这让"形状即体型"变成一个几乎零成本的机制
- 音效全部由 WebAudio 振荡器实时合成
