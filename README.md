# 拾色 / GRAFT

> **你不是在玩一个像素游戏 —— 你这具身体就是像素。**

一个像素平台跳跃游戏:你的身体由几十个 8×8 像素格组成,每一格都是从世界里抢来的材料。受伤是被削掉,变强是贴上去,而你的**形状**决定了你能去哪、打得过谁。

电脑和手机都能玩;手机上可以"添加到主屏幕",全屏横屏运行。

[设计文档 PRD](PRD.md) · [上线部署与安全](server/README.md) · [MIT License](LICENSE)

## 核心机制

| 机制 | 说明 |
|---|---|
| **身体 = 格子** | 你是一块 3×3 的肉像素。碰撞体只按包围盒算,所以削瘦了才钻得进缝 |
| **受伤 = 削格** | 没有血条。被撞就掉一格,掉光了就散架。回血不是喝药,是从地上抠材料贴回身上 |
| **材质 = 物理** | 贴什么就变成什么:石重、草轻、水软、火烫 |
| **形状 = build** | 要钻一格的缝,先把自己削成一片;要压塌脆地板,先吃成一块石头 |

### 五种材质 = 五个动词

不是数值差异,是**能做完全不同的事**:

| 材质 | 动词 | 能干什么 | 代价 |
|---|---|---|---|
| **肉** | 基准 | 什么都不会,也不必付出代价 | — |
| **草** | **生长** | 每 2 秒自己长一格。把身体摊长,就能**架在沟上走过去** | 变宽钻不进窄道;太轻压不住压板 |
| **石** | **压重** | 压住压板、压碎脆地板;按 `S` 放一块在地上当砝码 | 重到跳不起来 |
| **水** | **凝石** | 碰到岩浆,把它凝成石头,**一格水换一格桥** | 用一次就没了 |
| **火** | **焚烧** | 点着藤蔓,整面墙顺着烧穿 | 每 4.5 秒烧掉自己一格 |

三条组合,是关卡设计的主力:

- **草 + 沟** = 桥。身体比沟宽,就掉不下去。
- **石 + 压板** = 门。人不能一边踩着板一边进门,所以你得留一块石头替自己踩着。
- **水 + 岩浆** = 路,**火 + 藤蔓** = 开口。

## 操作

| 电脑 | 手机 | 行为 |
|---|---|---|
| `A` `D` / `←` `→` | 左下滑动条 | 移动 |
| `空格` / `W` | 右下 **跳** | 跳跃(按住跳更高) |
| 鼠标左键点身旁空位 | 直接点身旁空位 | 贴一格 |
| 鼠标右键点自己 | 直接点自己身体 | 削掉一格(材料回背包) |
| `E` / `Tab` | **改** | 打开改造面板(暂停,放大编辑身体) |
| `1`–`5` / 滚轮 | 点顶部材料 | 切换材质 |
| `S` / `Q` | **放** | 把选中材料放在脚下(压板要的砝码);手边有石块时改为捡起 |
| `Z` | **↶** | 撤销上一次贴/削(只撤自己的操作,不能用来回血) |
| `Esc` / `P` | 右上 **⏸** | 暂停菜单:继续 / 重来本关 / 选关 / 声音 |
| `R` / `M` | — | 重开本关 / 静音 |

## 八个关卡

**教学(一关只教一件事)**

1. **教学 1 · 削薄** —— 墙缝只有一格高,先把自己削掉一层
2. **教学 2 · 搭桥** —— 草让你变长,长到比沟还宽
3. **教学 3 · 压板** —— 站在板上门会开,走开就关。按 `S` 把石头留在板上
4. **教学 4 · 压碎** —— 够重,脆地板整片塌;塌完变窄,记得再削薄
5. **教学 5 · 凝石** —— 一格水换一格桥,数好再走
6. **教学 6 · 焚烧** —— 贴一格火,整面藤蔓墙顺着烧穿

**组合**

7. **组合 1 · 一石二鸟** —— 石头压板 + 草搭桥
8. **终关 · 四件事** —— 薄、长、重、水、火,全部用上

进度自动保存,下次打开可以"继续"。

## 这一版的体验改动

- **手感**:跳跃/落地的挤压拉伸、跑动扬尘、落地冲击按速度变化、受击击退和短暂顿帧、敌人起跳前蹲下预警、敌人受击无敌帧(不能贴脸秒杀)、道具靠近自动吸附、连续拾取音高上升
- **画面**:每关独立配色主题;三层视差背景(远景废墟 / 钟乳石 / 近景剪影);动态光照(玩家、出口、岩浆、发光蘑菇、水晶、身上的火);苔藓、草丛、垂藤、滴水、岩浆火星;每种材质有自己的纹理动画;角色受伤表情、濒死冒汗;敌人怒眉獠牙、石头怪发光眼和裂纹;伤害飘字、碎块飞溅
- **声音**:程序生成的循环配乐(每个主题一首,有 A/B 段),有敌人或濒死时加入鼓点;每种材质贴上去声音不同;濒死心跳
- **手机**:触屏手柄;竖屏时视野自动变成 3:4、画面更大;暂停菜单(重来 / 选关);撤销;第一关手指动画新手引导;切到后台自动暂停;iPhone 提示添加到主屏幕全屏玩;刘海屏安全区、震动反馈、PWA 图标;掉帧时分级降画质

## 本地运行

```bash
python3 -m http.server 8000      # 打开 http://localhost:8000
```

调试:`index.html?lv=3` 直接跳到第 4 关;游戏内按 `N` 跳关(生产构建会删掉这些)。

## 测试

```bash
bash tests/run_all.sh
```

包含:各关加载、**自动通关机器人**(证明每一关都能过)、战斗可行性、口令网关 9 项、Nginx 配置静态检查、生产构建检查。需要 Node 和 Python 3,零第三方依赖。
